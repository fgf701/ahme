# English Learning Mobile App

A simplified mobile app for learning English vocabulary, similar to Duolingo but focused specifically on English language learning.

## 📱 Features
- Interactive vocabulary lessons
- Multiple choice and translation quizzes
- Progress tracking with streaks and achievements
- Beautiful, modern UI design
- TypeScript for type safety

## 🚀 Getting Started

The main app is located in the `EnglishLearningApp/` directory.

```bash
cd EnglishLearningApp
npm install
npm run android  # or npm run ios
```

See the full documentation in [EnglishLearningApp/README.md](./EnglishLearningApp/README.md)

## 🛠️ Built With
- React Native 0.80.1
- TypeScript
- React Navigation
- Vector Icons
- Linear Gradients

## 📸 App Screens
- **Home**: Daily goals, streaks, and quick actions
- **Lessons**: Interactive vocabulary cards with flip animations
- **Quizzes**: Multiple choice and translation exercises
- **Progress**: Stats, achievements, and activity charts
- **Profile**: Settings and user management
